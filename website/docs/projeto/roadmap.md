# Roadmap

O desenvolvimento é feito em incrementos pequenos: uma issue, uma branch, um PR — com teste escrito antes e a documentação atualizada no mesmo PR. A lista completa de issues está em [`ROADMAP.md`](https://github.com/Bappoz/perceptor/blob/master/ROADMAP.md).
